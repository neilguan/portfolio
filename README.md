# Neil Guan — Portfolio

A readability-first portfolio covering a deterministic GPU voxel engine, local
AI infrastructure, reinforcement-learning robotics research, and hands-on
hardware.

## GitHub Pages

The repository includes a GitHub Actions workflow that publishes the static
site whenever `main` is pushed. The build automatically handles both a profile
site (`username.github.io`) and a project site (`username.github.io/repository`).

## Local preview

```powershell
npm install
npm run dev
```

## Verify the GitHub Pages build

```powershell
npm run build:pages
npm run preview:pages
```
